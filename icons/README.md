# Pineapple can icon set

An original, brand-neutral icon family inspired by the cheerful visual language of Finnish pineapple long drink. The artwork depicts a yellow beverage can with a bold pineapple emblem and navy wave accents.

## Recommended files

- `transparent/pineapple-can-transparent-1024.png` — transparent master for UI composition
- `mobile/app-icon-navy-1024.png` — primary native app-store source icon
- `mobile/app-icon-cream-1024.png` — light-background alternative
- `mobile/app-icon-green-1024.png` — green-background alternative
- `mobile/android-adaptive-foreground-1080.png` — transparent Android adaptive foreground
- `web/favicon.ico` — multi-resolution favicon (16, 32, 48 px)
- `web/apple-touch-icon-180.png` — Apple touch icon
- `web/pwa-icon-192.png` and `web/pwa-icon-512.png` — PWA icons
- `web/pwa-maskable-512.png` — maskable PWA icon with an expanded safe area

## Usage notes

- The transparent PNGs can be placed over arbitrary UI colors.
- Submit opaque square artwork for iOS; let the platform apply its corner mask.
- Use the adaptive foreground with a solid `#082754` Android adaptive-icon background.
- The primary palette is navy `#082754`, pineapple yellow, leafy green, cool silver, and cream `#FFF3CE`.
- The artwork is newly generated and intentionally contains no words, logos, or copied brand marks.
